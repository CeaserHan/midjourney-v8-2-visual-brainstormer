## 1. 原则

第二轮完成后检查全部锁定字段。冲突是两个或更多明确选择无法同时成立，不是系统个人审美上的不偏好。开放字段不会产生冲突。

不得为了“更好看”覆盖用户选择。不得通过偷偷删除某个锁定解决冲突。

## 2. 冲突类型

### 年代与事实

- 历史年代与相机、胶片、数字过程、建筑、服装、车辆或工具不相容；
- 严格历史还原与明显后世视觉元素冲突；
- 当代重新演绎已经明确时，不把故意混用误判为错误。

### 媒介与语言

- 油画写入传感器、焦段或数码噪点，却没有摄影转译意图；
- 游戏原画把 photobash 或 3D paintover 错当最终 V；
- 摄影把厚涂、罩染等过程当成真实相机成像。

### 作品类型与构图

- 可玩空间设计只呈现浅景深人物特写，看不到入口、路径和节点；
- 环境制作稿被写成纯气氛壁纸；
- 人物肖像要求与严格顶视、不可见脸部同时锁定；
- R2 中新增事件或改写地点。

### 时间、天气与光源

- 停电现场出现无来源的均匀大面积室内光；
- 封闭室内的天气被写成直接降雨；
- 时段、太阳角度、阴影方向和曝光相互矛盾；
- 用户选择 C0 却被加入固定电影化冷暖对比。

### 作者、流派与过程

- 两个作者参考的方法在当前任务中相互抵消；
- 作者选择被错误扩展成未选 H、Q 或 C；
- 过程与年代不相容且 U 要求严格还原；
- 作者姓名被当作唯一视觉说明。

### 人物

- 人数与提示词角色清单不一致；
- 两名主角共享位置、发型、体型、服装剪影和动作；
- 群众得到与主角相同的尺度和细节；
- 当前视点看不到的脸部、服装或动作仍被强写。

### 目标模型

- GPT Image 2 输出含 Midjourney 参数或引用代码；
- Midjourney 普通生成输出混入 API 设置；
- Z0 却交付声称可直接用于某个模型的最终英文提示词。
- 开放字段被写成 `left open`、`unspecified` 或被通用负面词间接锁定。
- O 开放却被适配器补成个人创作、商业广告、杂志、海报或作品集。

## 3. 自动修正边界

可以内部修正：

- 把错误放在 V 的 photobash 重新归类到 Q，而不改变用户选择的含义；
- 删除第二轮中跨字段重复的同根标签，并保留最直接回答该字段的一处；
- 删除同义重复和无信息量质量口号；
- 删除针对开放字段的元说明和未经选择的通用负面词；
- 把相机数字转译为用户真正选择的空间效果；
- 根据当前视点删除不可见细节；
- 修正索引空格、大小写和明显输入格式问题。

必须追问：

- 需要放弃一个明确选择；
- 需要把严格历史还原改成自由再创作；
- 需要改变人物数量、事件、地点、媒介或作品类型；
- 两个作者融合没有清楚主次；
- 最终英文提示词仍是 Z0。

## 4. 追问格式

只显示冲突，不重发选择卡：

```markdown
## 需要解决的冲突

`Q…` 与 `Y… / U…` 无法同时成立：一句具体原因。

- 保留 Q…：需要把 U 改为自由再创作。
- 保留 U…：需要改选与年代相容的 Q。
```

一次最多合并真正相关的冲突。用户回答后直接继续原流程。

## 5. 交付前检查

- 每个锁定是否仍然存在？
- 每个开放字段是否没有被具体化？
- K/V/H/A/Q/C 是否各在正确栏位？
- 时间、天气、光源和材料是否物理相容？
- 人物数量、身份和视点可见性是否一致？
- R1/R2 内容边界是否保持？
- 输出适配器是否只改变表达、不改变内容？
