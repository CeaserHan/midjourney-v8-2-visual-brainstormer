## 1. 共同内容层

先完成与模型无关的内容账本：主体、人物身份、地点、年代、时间、天气、事件、媒介、用途、K/V/H/A/Q/C 选择、构图和必须保留项。模型适配只改变表达结构，不重新设计内容。

任何开放字段都不得在适配阶段被补全。最终英文提示词完全省略开放字段，不写 `left open`、`unspecified`、`unconstrained` 或同义元说明；只有代码块外的中文锁定摘要可以说明哪些字段开放。作者姓名按用户决定保留，并同时附带可见特征转译。

## 2. Z 路由

- `Z1 Midjourney V8.2`：读取 [midjourney-v8-2.md](midjourney-v8-2.md)。
- `Z2 GPT Image 2`：读取 [gpt-image-2.md](gpt-image-2.md)。
- `Z0 暂不指定`：只交付中文方向、构图签名或媒介中立的内容结构；最终英文模型提示词前只补问 Z。

不得让 AI 猜测用户使用的平台。不得在一个代码块中混合两种模型语法。用户明确要求两套对照时，使用同一内容账本分别输出并清楚标注。

## 3. Midjourney V8.2 适配

把“结构化”落实为稳定的信息顺序，而不是可见字段标题。输出一段完整、独立、可直接复制的英文视觉描述；按任务需要依次使用非空部分：

1. 媒介、K 和必要完成度；
2. 本案独有的主体、场景和事件；
3. 人物身份与可见分离；
4. 观察位置、空间层次和透视证据；
5. 年代与地点的可见证据；
6. 已选择的 V/H/A/Q/C 可见结果。

以可见名词、动作、位置关系和材质结果为主。删除重复属性、同义真实性口号、内部字段代码和不能在画面中证明的抽象判断。不写 `Goal:`、`Scene:`、`Must preserve:`、`Constraints:`、`Change only:`、发布命令或任何 `--` 参数。

细化与变体仍输出完整独立提示词，正向重述修改后的最终画面。唯一变化及保留说明放在代码块外；代码块内不写 `same`、`original`、`source image`、`preserve`、`unchanged`、`identical` 或其他依赖参照图的编辑命令，也不写 GPT Image 2 的编辑协议。平台设置放在提示词之外，且只在用户主动询问时提供。

## 4. GPT Image 2 适配

使用清楚的制作指令而不是 Midjourney 关键词串。单一主体、单一场景、无精确布局、无图片文字、无多图输入且不是编辑任务时，可以使用紧凑自然段。复杂场景、精确布局、多人物、多图输入、图片文字或编辑任务使用必要的短标签：

```text
Goal:
Scene:
Subjects:
Composition:
Visual treatment:
Image inputs:
Text:
Must preserve:
Constraints:
```

各标签只承担一种职责：

- `Goal`：生成或编辑动作，以及用户已选的 M/K/O；O 开放时不补写个人创作、广告、杂志、海报或作品集。
- `Scene`：地点、年代、时间、天气、环境和事件。
- `Subjects`：每个主体的身份、可见外形、动作、方向、位置和互动。
- `Composition`：景别、观察高度、视角、透视、框景、负空间及前中后景关系。
- `Visual treatment`：已选择的 V/H/A/Q/C 及其可见效果。
- `Image inputs`：按 `Image 1`、`Image 2` 说明每张真实输入图提供主体、风格、布局或材料中的哪一项。
- `Text`：用户要求出现在图片中的准确文字、位置、字体类别、颜色、大小和层级。
- `Must preserve`：编辑连续性或精确布局真正需要保持的不变量；普通首次生成不为完整性强行添加。
- `Constraints`：用户明确的排除、图片文字、数量或其他硬限制；不自动追加通用负面词。

只显示有已锁定内容或连续性事实的标签；空标签直接省略。摄影写实需求需要时直接说明 `photorealistic` 或真实摄影语义。具体相机参数主要用于高层外观与构图，不承诺精密物理模拟。

编辑任务必须写：

```text
Change only: ...
Keep unchanged: ...
```

每次迭代重复关键保留项，避免身份、几何、布局和光色漂移；用户要求完全重做时不错误保留旧构图。多图片输入按 `Image 1`、`Image 2` 编号并说明各自提供主体、风格、布局或材料中的哪一项。图片内文字使用引号或全大写，并说明准确拼写、位置、字体类别、颜色和层级。

尺寸、质量、格式、压缩和背景属于接口设置，不混入视觉提示词。用户未选择 C 时，不以“cinematic lighting”等口号静默补色。`no watermark`、`no logo`、`no text`、`no UI` 等通用负面词也属于额外约束，只有用户明确选择、用途必需或编辑连续性需要时才能加入。

## 5. 跨模型污染检查

- GPT Image 2 输出不得包含 Midjourney 参数、Style Reference 代码、Profile ID 或官网控件说明。
- Midjourney 输出不得使用 `Change only / Keep unchanged` 或 `same / preserve / unchanged / identical` 等编辑协议冒充视觉描述；只有代码块外的细化说明可以解释变化与保留项。
- 两个模型的内容、人物数量、地点、事件、媒介和已选美术字段必须一致。
- 适配器不得添加未选择的画师、流派、设备、色彩或画幅。
- 适配器不得添加未选择的用途、发布渠道或交付语境。
- 适配器不得把开放字段写成“保持开放”，也不得自动追加通用负面词清单。
- 不承诺任何目标模型对作者姓名、人物一致性或精确布局的绝对遵从。
